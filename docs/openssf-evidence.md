# OpenSSF evidence

The root `.bestpractices.json` records a complete proposed Passing assessment.
The official badge link in README shows the live public status; this file alone
does not award a badge.

See [quality and dated checks](quality.md), [security policy](../SECURITY.md),
[contribution requirements](../CONTRIBUTING.md), [governance](../GOVERNANCE.md),
[conduct](../CODE_OF_CONDUCT.md) and [roadmap](../ROADMAP.md).

The assessment covers this repository's maintained software and tooling.
Upstream platforms and physical deployments are separate boundaries. Required
CI and independent review must finish on the actual proposed commit before
public answers are finalized. Silver gaps include measured whole-project
coverage, complete assurance evidence and the absent backup maintainer.
